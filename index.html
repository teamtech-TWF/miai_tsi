Recurring Cost — Minimum to Scale

  • Minimum open-source baseline: small cloud VM, Postgres + pgvector, open-source monitoring: 15K-35K THB / month
  • Hybrid paid-source fallback: Claude API for selected answers, managed backup / logs: 35K-75K THB / month
  • LINE cost kept low by prioritizing reply messages; push / broadcast depends on TSI package and volume
  • Maintenance / SLA included

Recommended minimum launch assumption: 20K-45K THB / month, excluding LINE overage, heavy paid API usage, and optional SLA retainer.

Appendix A

Zone 1: AI Q&A — Trusted Answers from TSI Knowledge

Closed-domain Business AdvisorMiAi ตอบจากองค์ความรู้ที่ TSI อนุมัติเท่านั้น ไม่ใช่ general AI และควบคุมแหล่งข้อมูล คำตอบ และการตรวจสอบย้อนหลังได้ชัดเจน
User JourneyAsk Question → Understand Intent → Retrieve TSI Knowledge → Generate Answer → Show Source → Collect Feedback
Core CapabilitiesNatural-language Q&A, TSI Knowledge Retrieval, Controlled Answer, Source Reference และ Quick Reply เพื่อช่วยต่อบทสนทนา
AI Control FrameworkApproved Source → Retrieval Threshold → Evidence Check → Answer Policy → Disclaimer → Audit Log พร้อม Model / Prompt / KB / Document traceability
Base scope ของ Zone 1 คือ LINE OA text chat, secure webhook, Claude Haiku 4.5, RAG, source reference, fallback, monitoring, traceability, rate limiting และ cost control โดยยังไม่รวม personalization, CRM, appointment และ MINI App
Appendix B

Zone 2: Personal Business Assistant

From Generic Answer to Recommendationยกระดับจากระบบที่รอให้ผู้ใช้ถาม ไปสู่ผู้ช่วยธุรกิจที่เข้าใจบริบท แนะนำสิ่งที่ควรทำ และติดตามผลอย่างต่อเนื่อง
User JourneyBuild Profile → Diagnose Business → Recommend Priority → Create Action Plan → Remind → Review Progress
Core CapabilitiesBusiness Profile, Business Health Check, Personalized Recommendation, Improvement Plan, Reminder & Follow-up และ Progress Summary
Data & Privacy Principlesเก็บข้อมูลเมื่อได้รับ consent, แยก PII จาก technical log, ให้ผู้ใช้ตรวจสอบ/แก้ไข/ถอนความยินยอม และรองรับการลบข้อมูลตามนโยบาย
Zone 2 ควรวางเป็น Optional Module หรือ Phase 2 เพื่อไม่ให้ proposal หลักซึ่งมุ่งเน้น Closed-domain AI Advisor มีราคา ระยะเวลา และความซับซ้อนสูงเกินไป
Appendix C

Zone 3: LINE Ecosystem

LINE OA + MINI App + Messaging APIใช้ LINE เป็นทั้ง communication layer, service layer และ relationship layer เพื่อพาจาก conversation ไปสู่ action จริง
Ecosystem ComponentsLINE OA Messaging, LINE MINI App, TSI Program Connection, Human Handoff และ Dashboard / CRM Connection
End-to-end JourneyLINE Entry → Ask MiAi → Diagnose Business → Receive Recommendation → Open MINI App → Complete Improvement Plan → Join Workshop or Apply → Receive Reminder → Follow-up with TSI
Scope PositioningPhase 1: Messaging / Rich Menu / Quick Reply, Phase 2: MINI App / Profile / Health Check / Booking, Phase 3: CRM / Human Workspace / Community / BI
  • Trigger: ถามเรื่องสต็อกหลายครั้ง → Next Best Action: เปิด Inventory Health Check
  • Trigger: สนใจเข้าร่วมโครงการ → Next Best Action: เปิด Application Form
  • Trigger: Checklist ยังไม่เสร็จ → Next Best Action: ส่ง Reminder ผ่าน LINE
Business value ของ Zone 3 คือการลดช่องว่างระหว่างการได้รับคำแนะนำกับการลงมือทำ เพิ่ม conversion เข้าสู่กิจกรรม TSI และสร้างความสัมพันธ์ต่อเนื่องกับผู้ประกอบการ
Appendix D

How the Three Zones Work Together

Zone 1 — Build TrustAI Q&A ตอบจากองค์ความรู้ TSI ที่ตรวจสอบได้ ช่วยลดคำถามซ้ำและทำให้เห็น knowledge gap
Zone 2 — Build RelevancePersonal Business Assistant เข้าใจบริบทและแนะนำสิ่งที่เหมาะกับผู้ประกอบการแต่ละราย
Zone 3 — Drive ActionLINE Ecosystem เชื่อมคำแนะนำไปสู่การสมัคร การจอง การติดตามผล และการได้รับความช่วยเหลือจริงจาก TSI
Strategic MessageZone 1 สร้างความเชื่อมั่น, Zone 2 สร้างความเกี่ยวข้อง, Zone 3 เปลี่ยนคำแนะนำให้เกิดการลงมือทำ
สรุปคือ MiAi 2.0 ไม่ได้เป็นเพียง AI ตอบคำถาม แต่เป็น architecture ที่ขยายจาก trusted knowledge ไปสู่ personalized guidance และ connected action ecosystem
